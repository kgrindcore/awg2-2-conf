# amnezia2conf

Конвертер ключей AmneziaVPN (`vpn://...`) в обычный `.conf` файл WireGuard / AmneziaWG, который можно импортировать в роутер Keenetic / Netcraze как клиентское подключение WireGuard.

## Зачем это нужно

Amnezia выдаёт ключ в виде строки `vpn://...`. Внутри лежит JSON, сжатый zlib и закодированный в base64. В нём есть готовый конфиг WireGuard, но с плейсхолдерами (`$PRIMARY_DNS`, `$SECONDARY_DNS` и т.п.) и в обёртке, которую роутер не понимает.

Скрипт распаковывает ключ, находит контейнер AmneziaWG или WireGuard, подставляет DNS и ключи и сохраняет чистый `.conf`.

## Требования

- Python 3.7+
- Никаких сторонних библиотек не нужно, только стандартная библиотека

## Использование

Сохраните ключ `vpn://...` в текстовый файл (например, `client.vpn`) и запустите:

```bash
python3 amnezia2conf.py client.vpn -o client.conf
```

Другие варианты:

```bash
# вывести конфиг в консоль, без сохранения в файл
python3 amnezia2conf.py client.vpn

# прочитать ключ из stdin
cat client.vpn | python3 amnezia2conf.py - -o client.conf

# показать расшифрованный JSON целиком (для отладки)
python3 amnezia2conf.py client.vpn --dump-json
```

### Параметры

| Параметр | Описание |
|---|---|
| `input` | Файл с ключом `vpn://...` или `-` для чтения из stdin |
| `-o`, `--output` | Путь к выходному `.conf`. Если не указан, конфиг выводится в консоль |
| `--dump-json` | Вывести расшифрованный JSON и выйти |

## Импорт в Keenetic / Netcraze

1. Откройте веб-интерфейс роутера.
2. Перейдите в **Интернет → Другие подключения → WireGuard**.
3. Нажмите **Загрузить из файла** и выберите полученный `.conf`.
4. Включите подключение и проверьте, что оно поднялось.

## Совместимость с AmneziaWG

По умолчанию Amnezia создаёт ключи для **AmneziaWG**, а не для чистого WireGuard. В таком конфиге есть дополнительные параметры обфускации:

```
Jc, Jmin, Jmax, S1, S2, H1, H2, H3, H4
```

Прошивка Keenetic / Netcraze поддерживает их только в свежих версиях KeeneticOS 4.x. Если импорт прошёл, но соединение не устанавливается, скорее всего, эти параметры не применились. Их можно задать вручную через CLI роутера. Синтаксис примерный, сверьтесь со справкой своей версии прошивки:

```
interface Wireguard0 wireguard asc <Jc> <Jmin> <Jmax> <S1> <S2> <H1> <H2> <H3> <H4>
system configuration save
```

Значения берутся из соответствующих строк сгенерированного `.conf`.

### AmneziaWG 1.5 / 2.0

Если скрипт выводит предупреждение о параметрах `I1`–`I5` или о диапазонах в `H1`–`H4` (вида `H1 = 100-200`), значит, ключ создан для AmneziaWG 1.5/2.0. Роутер, вероятно, такие параметры не поддерживает. В этом случае перегенерируйте ключ на сервере в режиме классического AmneziaWG или обычного WireGuard.

## Возможные проблемы

**«Не удалось расшифровать ключ»**
Проверьте, что в файле лежит именно строка `vpn://...` целиком, без обрезанных символов. Пробелы и переносы строк скрипт убирает сам.

**«В ключе нет контейнера AmneziaWG/WireGuard»**
Ключ создан для другого протокола (OpenVPN, XRay, Cloak и т.п.). Такие ключи этим способом в Keenetic не импортируются. Создайте на сервере Amnezia подключение с протоколом AmneziaWG или WireGuard.

**«Не заменены плейсхолдеры»**
В конфиге остались переменные вида `$SOMETHING`. Посмотрите содержимое ключа через `--dump-json` и подставьте недостающие значения в `.conf` вручную.
